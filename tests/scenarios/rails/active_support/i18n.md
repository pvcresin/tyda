# Rails / Active Support / I18n

## Resolve I18n singleton helpers

### update

```ruby
class Probe
  def title = I18n.t(:title)

  def label = I18n.translate(:label)

  def locale = I18n.locale

  def known = I18n.exists?(:title)
end
```

### result

```rbs
class Probe
  def title: -> String
  def label: -> String
  def locale: -> Symbol
  def known: -> bool
end
```

## A translation key can hold an array or a subtree

### update

```ruby
class Calendar
  def day_names = I18n.t("date.abbr_day_names")
  def month_names = I18n.t(:"date.month_names")
  def formats = I18n.t("date.formats")
  def label = I18n.t("date.formats.short")
end
```

### result

```rbs
class Calendar
  def day_names: -> Array[String]
  def month_names: -> Array[String?]
  def formats: -> Hash[Symbol, untyped]
  def label: -> String
end
```
