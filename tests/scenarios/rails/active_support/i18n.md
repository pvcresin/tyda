# Rails / Active Support / I18n

## Resolve I18n singleton helpers

### update

```ruby
class Probe
  def title = I18n.t(:title)

  def label = I18n.translate(:label)

  def locale = I18n.locale

  def known = I18n.exists?(:title)
end
```

class Probe
