# Ruby / Method / Define Method

## define_method with block

### update

```ruby
class A
  define_method(:hello) do
    "hello world"
  end
end
```

### result

```rbs
class A
  def hello: -> "hello world"
end
```

## define_method with args

### update

```ruby

  define_method(:double) do |x|
    x
  end
```

```rbs

  def double: (untyped x) -> untyped
```


## Register send define_method on singleton class receiver

### update

```ruby
class Group
  class Member
  end

  Member.singleton_class.send(:define_method, :build) { :member }

  class << self
    send(:define_method, :create) { :group }
  end
end

def build_member = Group::Member.build
def create_group = Group.create
```

### result

```rbs
class Group
  def self.create: -> :group
end

class Group::Member
  def self.build: -> :member
end

class Object < BasicObject
  def build_member: -> :member
  def create_group: -> :group
end
```
